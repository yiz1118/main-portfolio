## 2. Project data architecture

`data/projects.ts` supplies metadata, ordering, live/source URLs, roles, services, stack, image paths and captions, case copy, skills, and explicit demo limits. Presentations, filters, generated case routes, metadata, next-project navigation, sitemap, capture scripts, and tests consume it.

Each project is an **Independent Concept Project**, year **2026**. Briefs and objectives describe intent. No fake client, testimonial, award, or measurable commercial result was added. The main repository contains no source application copied from the six standalone projects.
